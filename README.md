## 📖 About The Project

This repository contains the source code for my personal portfolio website. It was designed from scratch with an emphasis on **modern aesthetics, clean typography, and engaging animations**. The visual identity relies heavily on a "Glassmorphism" UI layered over a fluid, animated background to create a unique user experience.

The site is built to be a comprehensive summary of my background, including my academic achievements (like ranking top in JEE Mains), my upcoming B.Tech in AI & Data Science, and a showcase of my technical arsenal ranging from Python and C++ to Prompt Engineering and Agentic AI.

### Built With

This project relies on core web technologies to remain lightweight and performant:

* **HTML5**: For semantic structuring.
* **CSS3**: For advanced styling, flexbox/grid layouts, animations, and the core Glassmorphism effects.
* **JavaScript**: For interactive elements like mobile navigation and dynamic project cards.
* **Google Fonts**: Utilizing the *Inter* font family for clean readability.
* **Font Awesome**: For scalable vector icons.

---

## ✨ Key Features

*   **Responsive Design:** Fully fluid layout that adapts flawlessly to mobile, tablet, and desktop viewports.
*   **Glassmorphism UI:** Translucent panels, subtle borders, and soft shadows over an animated background give the site a futuristic, premium feel.
*   **Animated Blob Background:** A dynamic, pure CSS/JS animated background using blurred blobs for visual depth.
*   **Multi-Page Architecture:** Organized logically into `Home`, `About`, `Projects`, and `Contact` sections for easy navigation.
*   **Interactive Elements:** Hover states, modal popups for skills, and clean CSS transitions enhance user interaction.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You only need a modern web browser to view the site. A local development server is recommended for the best experience (especially for resolving asset paths).

### Installation

1. **Clone the repository:**
   ```sh
   git clone https://github.com/ManasSoni-2009/portfolio.git
   ```
2. **Navigate into the directory:**
   ```sh
   cd portfolio
   ```
3. **Open the project:**
   *   *Option A (Simplest):* Double-click `index.html` to open it in your browser.
   *   *Option B (Recommended):* Use an extension like VS Code's "Live Server" or Python's built-in HTTP server:
       ```sh
       python3 -m http.server 8000
       ```
       Then navigate to `http://localhost:8000` in your browser.

## 🛠️ Customization Guide

If you are using this as a template or looking to adapt it for your own use, here are a few quick tips:

1.  **Colors & Background:** The animated blob colors and overall theme are likely controlled via CSS Variables in `css/style.css`. Look for `:root` to adjust the primary and secondary accents.
2.  **Typography:** The font is imported via Google Fonts in the `<head>` of each HTML file. Change the URL to swap `Inter` for your preferred font.
3.  **Content:** Update the text inside the HTML files. Make sure to replace the `assets/profile.jpg` with your own image and update the social links in the footer.
4.  **Skills Icons:** The skills section uses Font Awesome classes (e.g., `fa-python`). You can easily swap these out by referencing the Font Awesome library.
